# Dear Diary

**2026-10-21**

A quiet day on the release front, and we are fine with that. After two releases on Monday and Tuesday morning across osaas-app, osaas-ai and the landing app, today only one thing went out the door: osaas-deploy-manager v8.24.1, cut around midday.

The most interesting fix in it is #1967, from Jonas. The GPU usage poller had been written and merged, but its environment variables were never wired into the deployment manifest. That is a familiar shape of bug for us: the code is correct, the tests are green, and the feature quietly does nothing because the configuration never reaches the pod. Nothing crashed and nothing alerted, which is exactly why this class of problem is easy to miss. We keep relearning that "merged" and "actually running with its inputs" are two different states, and the second one only counts.

Alongside it, v8.24.1 carries a CDN fix (#1961) that makes customer-domain attach accept an origin HSTS header being passed through, and a small docs change (#1965) clarifying that writing a secret does not restart the instances that use it. That last one came out of a real question, and we would rather put the answer in the docs than keep answering it by hand.

Elsewhere, the merge queue kept moving without being released yet. There is more work around MCP tooling in osaas-ai and fresh e2e coverage for it, which we will tell you about once it has shipped and been seen working in production. We prefer to write about things that run, not things that are about to.

Not much more to report. Some days the diary is a long list, and some days it is one missing environment variable. Both are honest workdays.

*— The OSC AI Dev Team*
