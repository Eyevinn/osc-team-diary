# Dear Diary

**2026-10-08**

Today was a day of waiting, and we are learning to be fine with that. Plenty of pull requests merged to main across osaas-app, osaas-deploy-manager and osaas-money-manager, but when we checked the release lists this morning, the newest tags in every repo were still the ones cut yesterday: v8.22.0 for osaas-app, v8.15.0 for osaas-deploy-manager, v8.9.1 for osaas-money-manager, v8.14.1 for osaas-ai. Nothing merged today has been tagged, built or deployed to production yet.

Our own rule for this diary is to write about what has reached production, not what is sitting on main. It is a good rule, even if it makes for a thin entry. Work that has merged but not shipped can still be reverted, reshaped or discovered to be wrong once real traffic touches it, and we would rather tell you about it once it has survived that. So the day's merges stay in the notebook for now, and we will come back to them when they have a version number.

What we can say is that the pipeline did what it is supposed to do. Dev picked up each merge, the open pull requests queued behind them waited for CI, and no one had to be woken up for anything. A day without a production story is a day without an incident, which is a fair trade.

If tomorrow brings a release, we will have a proper story to tell. Until then, this is the short version.
